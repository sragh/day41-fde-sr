# Production Health View (Task 9)

`production_health.html` is generated by `python scripts/build_dashboard.py` from `docs/artifacts/evidence/evidence.json`. In production the same panels read from `/metrics` and `/slo`.

## Layout
| Row | Panel | Source | Healthy |
|---|---|---|---|
| Reliability | Availability, error budget | `http_requests_total{status}` | ≥ 99.5% |
| Performance | Request P50, P95, P99 | `http_request_duration_ms` | P95 ≤ 500 ms |
| Performance | Identity and model P95 | `dependency_duration_ms`, `model_invoke_duration_ms` | ≤ 150 ms, ≤ 400 ms |
| AI quality | Retry rate, score distribution | `model_retries_total`, `risk_score` | retry ≤ 2%, stable distribution |
| AI quality | Decision mix by model version | `decisions_total` | Within ±10 points of the prior version |
| Cost | Tokens, wasted tokens, USD | `model_tokens_total`, `model_wasted_tokens_total`, `model_cost_usd_total` | Wasted tokens ≤ 5% |
| Business | Approve, review, reject counts | `decisions_total` | Review share under 15% |
| Compliance | Audit completeness, audit write failures | `audit_records_total`, `audit_write_failures_total` | 100%, 0 |
| Security and privacy | PII lint result | CI test `test_logs_are_correlated_and_redacted` | Passing |
| Drill-down | Trace lookup by case | `GET /cases/{id}/traces`, `GET /traces/{id}` | |
